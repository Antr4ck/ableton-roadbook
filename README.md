# Ableton Roadbook

Roadbook interactif en français pour structurer un morceau : direction artistique, arrangement, checklist et notes. Base proposée : DnB atmosphérique en 4/4.

## Utilisation
Ouvrir index.html dans un navigateur. Aucune installation ni connexion nécessaire. Modifier le tempo, les plages de mesures et les notes. La sauvegarde locale dépend du navigateur : exporter régulièrement un JSON. Importer un JSON remplace les données actuelles après confirmation.

## Fonctionnalités
- Fiche projet et direction artistique
- Dix sections ajustables avec minutage calculé
- Checklist et progression
- Notes par section et écoute critique
- Sauvegarde locale, import/export JSON, impression PDF via le navigateur

## Max for Live
L’interface peut servir de base à un affichage dans jweb, à tester dans votre configuration. Ce dépôt ne contient pas de device .amxd ni de liaison à l’API Live. Les notes ne sont pas enregistrées dans le Live Set.

## Statut
Version autonome compacte issue du roadbook conçu dans la conversation ; interface réorganisée, non identique octet pour octet au premier HTML. Pas de dépendances externes ni de requêtes réseau. Les tests dans les différents navigateurs et dans Max restent à effectuer.
